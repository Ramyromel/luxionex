# Security Policy

## Supported versions

The `main` branch is the currently maintained version. This repository does
not currently publish versioned software releases.

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue. Use GitHub
Security Advisories to send a private report. Include a description, impact,
reproduction steps, and any relevant proof of concept or suggested mitigation.

We aim to acknowledge reports within 72 hours, then validate the issue, assess
its impact, and coordinate a fix and disclosure with the reporter.

## Scope

This policy covers the Next.js website, its dependencies, and the governance
documents in this repository. Governance documents describe policies and
processes; their presence does not imply that a corresponding software platform
or capability has been implemented here.
